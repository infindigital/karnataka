# Leader portraits

`president.jpg` is the state president (ಹೆಚ್. ಶಿವರಾಮೇಗೌಡ · ರಾಜ್ಯ ಅಧ್ಯಕ್ಷರು),
shown as a circular portrait in the "Heritage" section (`#heritage`).

It is currently a square crop taken from `../banner/photo-1.png` (leader with the Kannada flag shawl and state map). To use an
official studio portrait instead, just replace this file with a square image
(1:1, e.g. 900×900) of the same name — no code change needed.
