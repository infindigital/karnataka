# Leader portraits

Drop the state president's portrait here as **`president.jpg`** and it will
appear automatically in the "President's Message" section (`#leaders`).

- Recommended: a vertical/portrait crop (roughly 4:5), e.g. 1000×1250 px.
- Until the file is added, the section shows a styled KaRaVe emblem placeholder,
  so nothing looks broken.

Referenced by `index.html` → `.president__portrait img[src="assets/media/leaders/president.jpg"]`.
